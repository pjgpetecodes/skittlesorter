Preview Status and Current Guidance

Current preview status: Azure IoT Hub integration with Azure Device Registry (ADR) and Microsoft-backed X.509 certificate management remain in public preview and aren't recommended for production workloads. ADR is generally available for Azure IoT Operations; its integration with IoT Hub is still in preview.

ADR represents IoT Hub devices as Azure Resource Manager resources. Each IoT Hub links to one ADR namespace, and multiple hubs can share a namespace. To try the IoT Hub preview, create a new IoT Hub with ADR integration; there is no upgrade path for an existing hub. Existing hubs continue to work without interruption. DPS is required for every IoT Hub preview scenario, whether or not you enable certificate management.

Certificate management is optional. It manages operational X.509 certificates used to authenticate to IoT Hub after onboarding with a separate credential. The device submits a CSR during provisioning; DPS validates the onboarding credential and coordinates issuance from the namespace's ADR certificate authority. The device's private key remains on the device.
